Thành tích theo ID

Đăng nhập để mang thành tích đi

Google hoặc Facebook trả về ID cố định. Thành tích vẫn lưu trên trình duyệt này và gắn với ID đó.

Không đăng ký vẫn có thành tích riêng

Tạo ID ngẫu nhiên rồi ghi lại. Nhập đúng ID ở máy khác là mở lại được thành tích đã lưu cùng ID đó.

ID thiết bị (mặc định)
